# Задание 4.3. Телефонная книга на бинарном дереве

Это доработанное решение задания 2.1. Контакты больше не хранятся в массиве: каждый контакт находится в отдельном узле бинарного дерева поиска.

## Что изменено относительно 2.1

- `ContactBook` хранит указатель `root` на корень дерева, а не массив контактов.
- Узел `ContactNode` содержит `Contact`, служебный уникальный `id` и указатели `left`/`right`.
- Ключ дерева: фамилия, затем имя, затем отчество. Для одинаковых Ф.И.О. используется внутренний `id`, поэтому одинаковые имена разрешены.
- Вывод списка идёт симметричным обходом дерева, поэтому контакты отображаются в упорядоченном виде.
- Добавление выполняется обычной вставкой в BST.
- Удаление обрабатывает три случая: лист, один потомок, два потомка.
- Если при редактировании изменилось Ф.И.О., узел удаляется по старому ключу и вставляется по новому ключу.
- После каждых `CONTACT_BOOK_BALANCE_INTERVAL = 5` структурных изменений дерева выполняется автоматическая балансировка.
- Для балансировки используется алгоритм Day–Stout–Warren (DSW), который работает за `O(n)` и не требует массива узлов.
- В меню добавлены пункты просмотра состояния дерева и ручной балансировки.
- Сохранение в `contacts.txt` осталось совместимым с форматом решения 2.1 (`PHONEBOOK_TEXT_V1`).

## Периодическая балансировка

Счётчик `changes_since_balance` увеличивается после вставки, удаления и редактирования Ф.И.О. (то есть когда узел приходится переставлять в дереве). Изменение телефона, почты, места работы и других полей структуру дерева не меняет и счётчик не увеличивает. Когда счётчик достигает 5, вызывается `contact_book_balance()`.

Алгоритм DSW выполняет два этапа:

1. дерево поворотами преобразуется в правую цепочку (vine);
2. серия левых поворотов сжимает цепочку в почти идеально сбалансированное дерево.

После балансировки счётчик изменений обнуляется, а `balance_count` увеличивается.

## Меню

```text
1. Показать список контактов
2. Показать контакт подробно
3. Добавить контакт
4. Редактировать контакт
5. Удалить контакт
6. Найти контакт по Ф.И.О.
7. Показать состояние дерева
8. Сбалансировать дерево сейчас
0. Выход
```

Пункт 7 показывает количество узлов, высоту дерева, корректность свойства BST, число выполненных балансировок и число структурных изменений до следующей автоматической балансировки.

## Сборка в WSL / Linux

```bash
make clean
make
make test
make run
```

Дополнительная проверка памяти и неопределённого поведения:

```bash
make debug-test
```

## Сборка в Windows 11 / MSYS2

```powershell
mingw32-make clean
mingw32-make
mingw32-make test
mingw32-make run
```

Либо:

```powershell
.\build.bat
.\run_tests.bat
.\phonebook.exe
```

## Основные файлы

- `contact_book.h`, `contact_book.c` — узлы BST, CRUD, симметричный обход по индексу, DSW-балансировка;
- `main.c` — консольное меню;
- `storage.h`, `storage.c` — сохранение/загрузка;
- `input.h`, `input.c` — безопасный ввод;
- `tests.c` — автотесты дерева, CRUD, балансировки и хранения;
- `Makefile` — сборка и тестирование.
