Задание 4.3

WSL / Linux:
make clean
make
make test
make run

Windows / MSYS2:
mingw32-make clean
mingw32-make
mingw32-make test
mingw32-make run

Периодическая балансировка выполняется после каждых 5 структурных изменений дерева.
Пункты меню 7 и 8 позволяют показать состояние дерева и выполнить балансировку вручную.
