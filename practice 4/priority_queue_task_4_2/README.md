# Задание 4.2 — очередь с приоритетом

Приоритет: целое число от 0 до 255.
Чем больше число, тем выше приоритет. Приоритет 255 — максимальный.

Очередь реализована односвязным списком и хранится в порядке убывания приоритета.
Для сообщений с одинаковым приоритетом сохраняется FIFO-порядок.

Реализовано:
- добавление сообщения;
- извлечение первого сообщения;
- извлечение сообщения с точным приоритетом;
- извлечение сообщения с приоритетом не ниже заданного;
- просмотр и очистка очереди;
- случайная генерация сообщений;
- демонстрационная имитация выборки;
- автотесты.

## Linux / WSL

```bash
make
make run
make test
```

## Windows + MinGW

```powershell
mingw32-make
.\priority_queue.exe

```
