# Задание 4.1. Телефонная книга на двухсвязном упорядоченном списке

## Что изменено относительно задания 2.1

Раньше контакты хранились в массиве `Contact contacts[MAX_CONTACTS]`.
Теперь каждый контакт находится в отдельном динамически выделенном узле:

```c
typedef struct ContactNode {
    Contact contact;
    struct ContactNode *prev;
    struct ContactNode *next;
} ContactNode;
```

Телефонная книга хранит указатели на первый и последний узлы:

```c
typedef struct ContactBook {
    ContactNode *head;
    ContactNode *tail;
    size_t count;
} ContactBook;
```

Список является:

- **двухсвязным**: каждый узел содержит `prev` и `next`;
- **упорядоченным**: контакты автоматически располагаются по фамилии, затем по имени и отчеству;
- **динамическим**: узлы создаются через `malloc` и удаляются через `free`;
- **линейным, нециклическим**: `head->prev == NULL`, `tail->next == NULL`.

Внутренние поля одного контакта, например телефоны и почта, по-прежнему хранятся в массивах, как требовалось в задаче 2.1.

## Файлы

- `contact_book.h` — структуры контакта, узла и списка, объявления функций;
- `contact_book.c` — вставка по порядку, редактирование с перестановкой узла, удаление и освобождение памяти;
- `storage.c/.h` — сохранение и загрузка списка из `contacts.txt`;
- `input.c/.h` — безопасный консольный ввод;
- `main.c` — меню;
- `tests.c` — автотесты списка, связей, сортировки и файлов;
- `Makefile` — сборка GCC.

## Критерий сортировки

Функция `contact_compare` сравнивает:

1. фамилию;
2. имя;
3. отчество.

Используется `strcmp`. Новый узел сразу вставляется в правильное место, поэтому отдельная сортировка после добавления не нужна.

## Проверка упорядоченности вручную

Добавьте контакты в таком порядке:

```text
Петров Пётр
Андреев Андрей
Сидоров Сидор
Васильев Василий
```

В списке они должны появиться так:

```text
Андреев Андрей
Васильев Василий
Петров Пётр
Сидоров Сидор
```

Пункт 7 выводит список от `tail` к `head`, используя указатели `prev`.

## Работа с памятью

- `contact_book_add` выделяет память через `malloc`;
- `contact_book_delete` исключает узел из списка и вызывает `free`;
- `contact_book_destroy` освобождает все оставшиеся узлы перед завершением программы;
- при редактировании узел не создаётся заново: он отсоединяется и вставляется в новое место.

Формат `contacts.txt` совместим с предыдущей версией проекта.
