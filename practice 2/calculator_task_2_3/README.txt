Калькулятор, задание 2.3

Главное отличие от задания 2.2:
- меню не содержит switch для выбора арифметической операции;
- каждая команда хранит указатель на функцию;
- список команд создаётся динамически через malloc/realloc;
- меню строится циклом по фактически зарегистрированным командам;
- выбранная операция вызывается через command->operation.

Сборка на Windows 11 через MinGW/MSYS2:

    mingw32-make

Запуск автотестов:

    mingw32-make test

Запуск калькулятора:

    mingw32-make run

Полная пересборка:

    mingw32-make rebuild

Очистка:

    mingw32-make clean

Русский текст выводится через Unicode API Windows. Команда chcp 65001 не нужна.
