# Задание 3.1. Маска прав доступа

Программа:

1. Принимает права в цифровом или буквенном виде.
2. Получает права реального файла через `stat()`.
3. Изменяет текущую маску командами, похожими на `chmod`, не применяя изменения к файлу.
4. Показывает буквенное, цифровое и битовое представление.
5. Содержит отдельные автоматические тесты.

## Структура

- `main.c` — только интерфейс и меню.
- `permissions.c/.h` — преобразование форматов прав.
- `chmod_parser.c/.h` — разбор и применение chmod-команд к маске в памяти.
- `file_info.c/.h` — получение данных через `stat()`.
- `tests.c` — тесты логики.
- `Makefile` — сборка, запуск и тестирование.

## Поддерживаемые форматы

Начальная маска:

```text
755
0755
rwxr-xr-x
-rwxr-xr-x
```

Команды изменения:

```text
u+x
g-w
o=r
a+rx
ug+wx
g=u
u+r-w
u+x,g-w,o=r
755
rwxr-x---
```

Поддерживаются классы `u`, `g`, `o`, `a`, операции `+`, `-`, `=`,
права `r`, `w`, `x`, копирование прав между классами и несколько команд
через запятую. Это полный разбор chmod-команд в рамках обычных девяти
битов `rwxrwxrwx`, которые требуются заданием.

## Проверка исполняемого атрибута в Linux

Создайте файл:

```bash
printf '#!/bin/sh\necho "Файл запущен"\n' > demo.sh
chmod 644 demo.sh
./demo.sh
```

При маске `644` запуск должен завершиться ошибкой доступа. Затем:

```bash
chmod u+x demo.sh
./demo.sh
```

После установки пользовательского бита `x` файл должен запуститься.

Программа из задания сама не вызывает `chmod()` и не изменяет файл, потому
что это прямо запрещено условием. Она рассчитывает новую маску только в памяти.
