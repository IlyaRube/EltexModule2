# Модуль 2. Лекция 3. Задание 3.2

Программа имитирует обработку IPv4-пакетов.

Пользователь передаёт через аргументы запуска:

1. IP-адрес шлюза;
2. маску подсети;
3. количество пакетов.

Для каждого пакета генерируется случайный 32-битный IPv4-адрес назначения.
Затем программа сравнивает адрес подсети шлюза и адрес подсети назначения:

```text
(gateway & mask) == (destination & mask)
```

Если выражение истинно, пакет предназначен узлу своей подсети.
После обработки выводится количество и процент локальных и внешних пакетов.

## Структура

```text
main.c          — разбор аргументов и вывод
ipv4.c/.h       — IPv4-адреса, маски и сравнение подсетей
simulation.c/.h — логика обработки пакетов
tests.c         — автоматические тесты
Makefile        — сборка и запуск
```

Интерфейс отделён от логики. Модуль `simulation.c` ничего не знает о
`printf`: вывод каждого пакета выполняется через функцию-наблюдатель,
переданную из `main.c`.

## Сборка

```bash
make
```

## Запуск напрямую

```bash
./ipv4_simulator 192.168.1.1 255.255.255.0 20
```

## Запуск через Makefile

```bash
make run
```

Собственные аргументы:

```bash
make run GATEWAY=10.0.0.1 MASK=255.0.0.0 PACKETS=50
```

## Тесты

```bash
make test
```

## Очистка

```bash
make clean
```

## Примеры ошибок

Некорректный IP:

```bash
./ipv4_simulator 300.1.1.1 255.255.255.0 10
```

Разорванная маска:

```bash
./ipv4_simulator 192.168.1.1 255.0.255.0 10
```

Некорректное количество пакетов:

```bash
./ipv4_simulator 192.168.1.1 255.255.255.0 0
```
